    深拷贝和浅拷贝

    # 深拷贝和浅拷贝

    # 区别

    • 深拷贝和浅拷贝最根本区别在于是否真正获取一个对象的复制实体，而不是引用。

    • 浅拷贝只增加了一个指针指向已存在的内存地址；浅拷贝只复制一层对象的属性。

    • 深拷贝增加了一个新的指针并且申请了一个新的内存，让新增的指针指向新的内存；深拷贝递归复制对象所有层级的属性。

    # 实现方式

    # 数组的浅拷贝

    • Array.concat()

      const arr = [1, 2, 3]
const newArr = arr.concat()
newArr.push(4)
console.log(arr, newArr) // [1, 2, 3]; [1, 2, 3, 4]

    • Array.slice()

      const arr = [1, 2, 3]
const newArr = arr.slice()
newArr.push(4)
console.log(arr, newArr) // [1, 2, 3]; [1, 2, 3, 4]

    • 扩展运算符(...)

      const arr = [1, 2, 3]
const newArr = [...arr]
newArr.push(4)
console.log(arr, newArr) // [1, 2, 3]; [1, 2, 3, 4]

    • Array.from

      const arr = [1, 2, 3]
const newArr = Array.from(arr)
newArr.push(4)
console.log(arr, newArr) // [1, 2, 3]; [1, 2, 3, 4]

    # 数组的深拷贝

    const deepCloneArr = arr => arr.reduce((prev, next) => next instanceof Array ? [...prev, deepCloneArr(next)] : [...prev, next], [])

    # 对象的浅拷贝

    • Object.assign()
    const obj = {
	x: 1,
	y: 2,
	m: {
		n: 6
	}
}
const newObj = Object.assign({}, obj)
newObj.z = 3
newObj.m.n = 8
console.log(obj, newObj) // {x: 1, y: 2, m: {n: 8}}; {x: 1, y: 2, z: 3, m: {n: 8}}

    const deepCloneObj = obj => Object.entries(obj).reduce((prev, [key, value]) => {...prev, [key]: value}, {})

    # 手写深拷贝

    // 使用weekmap: 解决循环引用问题，我们可以开辟一个存储空间，来存储当前对象和拷贝对象的对应关系
// 这个存储空间，需要可以存储key-value形式的数据，且key是一个引用类型。
// 我们可以选WeakMap这种数据结构
function deepClone(obj, hash = new WeakMap()) {
	// 处理 null 和 undefined 类型
	if(obj == null) return obj
	// 处理日期类型
	if(obj instanceof Date) return new Date(obj)
	// 处理正则类型
	if(obj instanceof RegExp) return new RegExp(obj)
	// 处理基本类型值和函数
	if(typeof obj !== 'object') return obj

	if(hash.has(obj)) return hash.get(obj)
	const newObj = obj instanceof Array ? [] : {}

	hash.set(obj, newObj)
	for(let key in obj) {
		if(hasOwnProperty.call(obj, key)) {
			newObj[key] = typeof obj[key] === 'object' ? deepClone(obj[key], hash) : obj[key]
		}
	}

	return newObj
}
