    CSS 中 display visibility opacity 的区别

    # CSS 中 display visibility opacity 的区别

    display 属性用来设置元素是否被视为块级或行级盒子，以及用于子元素布局； visibility 属性用来显示或隐藏元素而不更改文档的布局； opacity 属性用来指明一个元素的不透明度。

    display、visibility、opacity 这三个属性分别取值 none、hidden、0 都能使元素在页面不可见，但是区别很大。

    # 是否占据页面空间

    元素设置属性值 visibility: hidden 、opacity: 0 都会占据页面空间，浏览器会解析该元素，而属性值 display: none 不会占据页面空间，浏览器不会解析该元素。

    # 子元素继承

    使用display和opacity属性时，子元素会继承父元素属性且和父元素显示效果一样，子元素设置的opacity和display属性不起作用； 使用visibility属性时，子元素不会继承父元素属性，父元素属性为visibility: hidden，子元素设置为visibility: visible，子元素可以继续显示。

    # 自身绑定的事件是否能触发

    display: none时，元素在页面已经不存在，所以元素上面绑定的事件无法触发， visibility: hidden时，元素虽然占据空间，但绑定的事件无法触发； opacity: 0时，元素上面绑定的事件可以触发。

    # 是否影响其他元素触发事件

    display: none时，元素在页面已经不存在，不会遮挡其他元素，就不会影响其他元素触发事件； visibility: hidden时，不会影响其他元素触发事件； opacity: 0时，如果遮挡其他元素，则其他元素就不会触发事件。

    # 是否产生回流(reflow)

    回流：当页面中的一部分(或全部)因为元素的规模尺寸，布局，隐藏等改变而需要重新构建。这就称为回流(也有人会把回流叫做是重布局或者重排)。每个页面至少需要一次回流，就是在页面第一次加载的时候。

    display属性会产生回流，而visibility和opacity属性不会产生回流

    # 是否产生重绘(repaint)

    重绘：当页面中的一些元素需要更新属性，而这些属性只是影响元素的外观，风格，而不会影响布局的时候，比如background-color。则称为重绘。

    display和visibility属性会产生重绘，而opacity属性不一定产生重绘

    # 是否支持transition动画

    display属性不支持transition动画，visibility和opacity支持transition动画

    # 总结

    display: none visibillity: hidden opacity: 0
    是否占据页面空间 不占据 占据 占据
    子元素继承 继承 不继承 继承
    自身绑定的事件是否能触发 不能触发 不能触发 能触发
    是否影响其他元素触发事件 不影响 不影响 影响
    是否产生回流 产生回流 不产生回流 不产生回流
    是否产生重绘 产生重绘 产生重绘 不会定产生重绘
    是否支持transition动画 不支持 支持 支持
